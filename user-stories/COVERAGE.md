The bulk builder stories (US-APP-05 to US-APP-07) record that `delete()` and `del()` physically delete regardless of read mode, while `softDelete()` is recoverable. Relation counts, aggregates and existence queries automatically apply the related model’s read filter; arbitrary SQL subqueries require explicit predicates. Model fetch hooks do not filter raw/POJO paths or arbitrary joined tables; see the query story ([US-APP-02](query-deleted-records/us-app-02-query-deleted-records.md)) and [scope contract](../docs/reference/scope-contract.md#paths-that-bypass-model-fetch-hooks).
